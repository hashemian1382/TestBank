## پوشش رفتاری

### درسنامه و سوال

- ایجاد، ویرایش، پیش‌نویس، انتشار و بازخوانی داده از حافظه.
- حفظ LaTeX، جدول، تصویر، زیرنویس، عرض و برچسب‌ها.
- اتصال چند درسنامه‌ی موجود/جدید به سوال، اولویت اتصال مستقیم، نبود لینک تکراری.
- ثبت اتمی سوال و درسنامه‌های جدید؛ rollback در خطای اعتبارسنجی و سهمیه‌ی ذخیره‌سازی.
- حذف درسنامه و پاک‌شدن اتصال از سوال‌های فعال و غیرفعال، بدون حذف سوال.
- قطع اتصال بدون حذف خود درسنامه و محدودیت جابه‌جایی درسنامه‌ی متصل بین درس‌ها.
- عدم نمایش پیش‌نویس در فهرست و مسیر مستقیم برای کاربر عادی.
- استمرار رفتار خرید/عدم مالکیت در صفحه‌ی مطالعه.
- حفظ ارجاع میان‌درسی موجود در سوال نمونه‌ی قدیمی بدون تغییر مالکیت آن.

### ورود گروهی

- ساخت مبحث جدید، استفاده‌ی دوباره و ترتیب صحیح در همان درس.
- یکسان‌سازی حروف فارسی/عربی و فاصله/نیم‌فاصله.
- سوال چنددرسی با نام ساده و scope صریح `{subject,title}`.
- عدم ایجاد مبحث برای ردیف خراب؛ خطاهای شماره‌دار و امکان اصلاح فقط ردیف‌های ناموفق.
- انواع ورودی خراب، مبحث خالی، درس ناموجود، منبع اشتباه، گزینه/پاسخ/زمان/سطح نامعتبر.
- شماره‌گذاری صریح پاسخ از صفر و یک، و رفتار صفر قدیمی.
- حفظ شناسه‌های درسنامه و وضعیت غیرفعال در ورودی JSON.
- اجرای واقعی مثال‌های تحویلی در `examples/bulk-questions.json`.

### ادغام و تغییر نام

- حفظ شناسه در تغییر نام، کنترل عنوان خالی و تکراری، پشتیبانی از نام قدیمی در ورود بعدی.
- پیش‌نمایش بدون mutation و تأیید صریح قبل از ادغام.
- انتقال سوال‌های فعال/غیرفعال، درسنامه‌ها و blueprintهای کاربران دیگر.
- بازطبقه‌بندی نتایج قبلی بدون دوباره‌شماری سوال چندمبحثی.
- حفظ نمره‌ی کل، آمار درس، جواب‌های ثبت‌شده، زمان و ترتیب آزمون.
- محفوظ‌ماندن مجموعه‌ها و نشان‌ها.
- ادغام‌های زنجیره‌ای و resolve شدن شناسه‌های حذف‌شده در import و فیلتر قدیمی.
- رد ادغام بین درس‌ها، مبدأ حذف‌شده/نامعتبر، انتخاب تک‌مبحثی و برخورد با مقصد انتخاب‌نشده.
- rollback کامل ادغام هنگام پر بودن حافظه.
- جلوگیری از حذف مبحث دارای ارجاع و تغییر ترتیب اتمی.

### سازگاری و رگرسیون

- مهاجرت افزایشی داده‌های v2 بدون reseed و با حفظ کاربر، نشست، تنظیمات و محتوای سفارشی.
- بازسازی snapshot سوابق قدیمی کامل؛ توقف محافظتی برای سوابق قدیمی فاقد جزئیات سوال حذف‌شده.
- عدم پاک‌کردن بی‌صدای JSON خراب.
- دریافت نسخه‌ی تازه‌ی ذخیره‌سازی برای جلوگیری از بازنویسی داده‌ی تب دیگر با cache قدیمی.
- مستقل‌بودن اشیای برگشتی API از حافظه‌ی داخلی.
- ادامه‌ی کار کیف پول، خرید، مجموعه، انتخاب سوال و شروع/ادامه/پایان آزمون.
- اعتبارسنجی همه‌ی سوال‌ها و درسنامه‌های seed در مسیر ویرایش سازگار.
- Modal تو‌در‌تو، Escape فقط برای لایه‌ی بالا، قفل اسکرول، خروج بدون ذخیره و نمای موبایل.
- تست‌های Playwright در صورت رخ‌دادن خطای uncaught JavaScript شکست می‌خورند؛ در اجرای موفق خطایی از این نوع رخ نداد.

## نکات باقی‌مانده‌ی محیط توسعه

1. بک‌اند هنوز متصل نیست؛ این تغییرات امنیت سرور، ذخیره‌سازی ابری یا اشتراک داده بین دستگاه‌ها ایجاد نمی‌کنند.
2. سوابق v2 پاسخ صحیح تاریخی هر سوال را نداشتند. snapshot آن‌ها از سوال‌های فعلی ساخته می‌شود؛ اطلاعات حذف‌شده/تغییرکرده‌ی پیش از این نسخه را نمی‌توان از هیچ بازسازی‌ای با قطعیت بازیابی کرد. ادغام سابقه‌ی ناقص به‌جای حدس‌زدن متوقف می‌شود.
3. داده‌های محلی به origin و مرورگر وابسته‌اند. پاک‌کردن حافظه‌ی مرورگر یا دکمه‌ی بازنشانی، داده‌ها را از بین می‌برد. خروجی JSON درسنامه/سوال جای پشتیبان کامل داده‌های کاربران نیست.
4. آزمون مرورگر در Chromium و دو اندازه‌ی دسکتاپ/موبایل انجام شده است؛ ادعای تست روی همه‌ی مرورگرها یا تضمین نبود همه‌ی خطاها وجود ندارد.
5. workflowهای بررسی کیفیت و deploy به‌روز شده‌اند، اما این تغییرات **به GitHub push نشده‌اند** و اجرای GitHub Actions در این محیط انجام نشده است.

## تغییرات کمکی

- CSS و فونت‌های KaTeX با نسخه‌ی نصب‌شده یکسان و محلی شدند؛ فونت Vazirmatn هم در بسته قرار دارد.
- Vite از `7.3.2` به patch سازگار `7.3.6` ارتقا یافت و وابستگی دارای هشدار امنیتی به‌روز شد؛ major چارچوب‌ها تغییر نکرد.
- کد فرمول، React و داده‌ی seed در chunkهای جدا بسته‌بندی شدند؛ مسیر نسبی GitHub Pages و HashRouter حفظ شده‌اند.
- قراردادهای سرویس، رفتار چنددرسی import، مهاجرت و محدودیت‌های داده‌ی تاریخی در README مستند شده‌اند.
